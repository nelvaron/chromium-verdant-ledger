# Privacy policy

Verdant Ledger Light is a browser theme. It consists of a manifest with
colors, icons, and translated text, and contains no code.

- It collects, stores, and transmits no data of any kind.
- It requests no permissions and cannot read or change web pages.
- It makes no network requests.

The browser and the store you install it from have their own privacy
policies, which apply to them.

Questions: [open an issue](https://github.com/nelvaron/chromium-verdant-ledger/issues).
