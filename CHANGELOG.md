# Changelog

All notable changes to Verdant Ledger Light for Chrome and Edge are listed
here. The project follows [Semantic Versioning](https://semver.org/).

## 1.0.0 - 2026-10-12

First public release.

- Calm light theme for Chrome, Edge, and other Chromium browsers, in the
  colors of Verdant Ledger Light for VS Code: a pale gray-green frame, a
  near-white toolbar and active tab, a white address bar, and deep evergreen
  text.
- Sets every color Chromium reads from a theme, including the New Tab page,
  where links are forest green and the Google logo is a single sage color.
- WCAG AA contrast for tab titles, bookmarks, the address bar, and New Tab
  page text, also in background windows, and 5.42:1 for toolbar icons.
- Name and description in English and Bulgarian.
